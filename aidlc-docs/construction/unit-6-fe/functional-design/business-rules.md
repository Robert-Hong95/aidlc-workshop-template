# Business Rules - Unit 6-FE (Store/Table 관리 UI)

## 매장 관리 규칙

### BR-6FE-01: 매장 등록 필수 필드
- 매장명: 필수, 1~50자
- 주소: 선택
- 전화번호: 선택

### BR-6FE-02: 매장 전환
- AdminHeader 매장명 클릭 시 드롭다운으로 전환
- 전환 시 현재 페이지 데이터 자동 리페치
- auth-store의 storeId/storeName 업데이트

## 테이블 관리 규칙

### BR-6FE-03: 테이블 비밀번호 정책
- 4자리 숫자 PIN만 허용
- 정규식: `/^\d{4}$/`
- 입력 시 숫자 키패드 표시 (inputMode="numeric")

### BR-6FE-04: 테이블번호 유효성
- 양의 정수만 허용
- 같은 매장 내 중복 불가 (서버 검증)

### BR-6FE-05: 이용 완료 처리
- 확인 팝업에 총 주문 금액 요약 표시
- 확인 시 세션 종료 API 호출
- 세션 종료 후 테이블 상태 "비활성"으로 변경

### BR-6FE-06: 주문 삭제
- ConfirmDialog로 2차 확인 필수
- 삭제 후 테이블 총 주문액 재계산

## 과거 내역 규칙

### BR-6FE-07: 날짜 필터
- 프리셋: 오늘, 최근 7일, 최근 30일
- 커스텀: 시작일~종료일 범위 선택
- 기본값: 오늘
- 종료일은 시작일 이후여야 함

### BR-6FE-08: 뷰 토글
- 리스트/카드 뷰 전환 가능
- 선택한 뷰 모드는 localStorage에 저장하여 유지
