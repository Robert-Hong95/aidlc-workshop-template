# Business Rules - Unit 7-FE (Menu UI)

### BR-7FE-01: 메뉴 필수 필드
- 메뉴명: 필수, 1~100자
- 가격: 필수, 100원 ~ 1,000,000원
- 카테고리: 필수
- 설명: 선택, 최대 500자
- 이미지: 선택 (없으면 플레이스홀더)

### BR-7FE-02: 이미지 업로드
- 허용 형식: jpg, jpeg, png, webp
- 최대 크기: 5MB
- 업로드 전 로컬 미리보기 (FileReader)

### BR-7FE-03: 카테고리 관리
- 추가/수정/삭제 + 순서 변경 가능
- 하위 메뉴가 있는 카테고리 삭제 시 경고
- 카테고리명: 필수, 1~50자

### BR-7FE-04: 메뉴 순서
- 드래그 앤 드롭으로 순서 변경 (@dnd-kit)
- 변경 후 서버에 순서 저장

### BR-7FE-05: 고객 메뉴 표시
- 카테고리 순서대로 표시
- 각 카테고리 내 메뉴 순서대로 표시
- 터치 친화적 (최소 44x44px 버튼)
