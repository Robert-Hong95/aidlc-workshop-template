# 테이블오더 서비스 - 요구사항 정의서

## Intent Analysis

- **User Request**: 테이블오더 서비스 신규 구축
- **Request Type**: New Project (Greenfield)
- **Scope**: System-wide (고객 UI, 관리자 UI, Backend API, Database)
- **Complexity**: Complex (다중 매장, 실시간 통신, 인증/세션 관리, 파일 업로드)

---

## 기술 스택 결정사항

| 영역 | 기술 |
|------|------|
| Backend | Java + Spring Boot |
| Frontend | Next.js (React 기반) |
| Database | MySQL |
| 배포 환경 | 로컬 개발 환경 (Docker Compose) |
| 이미지 저장 | 서버 로컬 파일 시스템 |
| 실시간 통신 | Server-Sent Events (SSE) |
| 인증 | JWT 토큰 기반 |

## 1. 기능 요구사항 (Functional Requirements)

### 1.1 고객용 기능

#### FR-C01: 테이블 태블릿 자동 로그인 및 세션 관리
- 관리자가 초기 설정 1회 수행 (매장 식별자, 테이블 번호, 테이블 비밀번호)
- 로그인 정보 로컬 저장 후 자동 로그인
- 태블릿 전용 웹앱 (고정 URL) + QR 코드 모바일 웹 모두 지원

#### FR-C02: 메뉴 조회 및 탐색
- 메뉴 화면이 기본 화면
- 카테고리별 메뉴 분류 및 표시
- 메뉴 상세 정보: 메뉴명, 가격, 설명, 이미지
- 카테고리 간 빠른 이동
- 카드 형태 레이아웃, 터치 친화적 (최소 44x44px)

#### FR-C03: 장바구니 관리
- 메뉴 추가/삭제, 수량 조절
- 총 금액 실시간 계산
- 장바구니 비우기
- 클라이언트 측 로컬 저장 (새로고침 시 유지)
- 서버 전송은 주문 확정 시에만

#### FR-C04: 주문 생성
- 주문 내역 최종 확인 후 주문 확정
- 주문 성공: 주문 번호 표시 → 장바구니 비우기 → 메뉴 화면 자동 리다이렉트
- 주문 실패: 에러 메시지 표시, 장바구니 유지
- 주문 정보: 매장 ID, 테이블 ID, 메뉴 목록(메뉴명, 수량, 단가), 총 금액, 세션 ID

#### FR-C05: 주문 내역 조회
- 주문 시간 순 정렬
- 주문별 상세: 주문 번호, 시각, 메뉴/수량, 금액, 상태(대기중/준비중/완료)
- SSE 기반 주문 상태 실시간 업데이트 (MVP 포함)
- 현재 테이블 세션 주문만 표시
- 페이지네이션 또는 무한 스크롤

### 1.2 관리자용 기능

#### FR-A01: 매장 인증
- 매장 식별자 + 사용자명 + 비밀번호 입력
- 16시간 세션 유지 (JWT 토큰)
- 브라우저 새로고침 시 세션 유지
- 비밀번호 bcrypt 해싱, 로그인 시도 제한

#### FR-A02: 실시간 주문 모니터링
- SSE 기반 주문 목록 실시간 업데이트 (2초 이내)
- 그리드/대시보드 레이아웃: 테이블별 카드 형태
- 각 테이블 카드: 총 주문액, 최신 주문 n개 미리보기
- 주문 카드 클릭 시 전체 메뉴 목록 상세 보기
- 주문 상태 변경 (대기중 → 준비중 → 완료)
- 신규 주문 시각적 강조
- 테이블별 필터링

#### FR-A03: 테이블 관리
- 테이블 태블릿 초기 설정 (번호, 비밀번호, 16시간 세션)
- 주문 삭제 (확인 팝업 → 즉시 삭제 → 총 주문액 재계산)
- 테이블 세션 종료 (이용 완료 → 주문 내역 과거 이력 이동 → 리셋)
- 과거 주문 내역 조회 (시간 역순, 날짜 필터링)

#### FR-A04: 메뉴 관리 (MVP 포함)
- 메뉴 CRUD (등록, 조회, 수정, 삭제)
- 카테고리별 조회
- 메뉴 정보: 메뉴명, 가격, 설명, 카테고리, 이미지 URL
- 메뉴 노출 순서 조정
- 필수 필드 검증, 가격 범위 검증

#### FR-A05: 매장 관리
- 다중 매장 지원
- 매장 등록 API 제공

### 1.3 시스템 기능

#### FR-S01: 이미지 업로드
- 서버 로컬 파일 시스템에 메뉴 이미지 업로드
- 업로드된 이미지 URL 반환

#### FR-S02: SSE 실시간 통신
- 관리자: 신규 주문 알림, 주문 상태 변경 알림
- 고객: 주문 상태 변경 알림

## 2. 비기능 요구사항 (Non-Functional Requirements)

### NFR-01: 성능
- 주문 생성 API 응답 시간: 2초 이내
- SSE 이벤트 전달: 2초 이내
- 메뉴 조회 API 응답 시간: 1초 이내

### NFR-02: 보안
- JWT 토큰 기반 인증
- 비밀번호 bcrypt 해싱
- 로그인 시도 제한
- API 인증 필수 (공개 API 제외)

### NFR-03: 사용성
- 터치 친화적 UI (최소 44x44px 버튼)
- 반응형 관리자 웹앱 (데스크톱 + 태블릿/모바일)
- 고객 UI: 태블릿 + 모바일 웹 지원

### NFR-04: 배포
- Docker Compose 기반 로컬 개발 환경
- Backend, Frontend, MySQL 컨테이너 구성

## 3. 제외 범위 (Out of Scope)

- 결제 처리 (카드, 현금, PG사 연동)
- 영수증 발행, 환불, 포인트/쿠폰
- OAuth/SNS 로그인, 2FA
- 이미지 리사이징/최적화
- 푸시/SMS/이메일 알림
- 주방 전달, 재고 관리
- 데이터 분석, 매출 리포트
- 직원 관리, 예약, 리뷰, 다국어
- 외부 연동 (배달, POS, 소셜미디어)

- 매장 인증 (16시간 JWT 세션)

- 테이블 관리 (초기 설정, 주문 삭제, 이용 완료, 과거 내역)
- 메뉴 관리 (CRUD)
