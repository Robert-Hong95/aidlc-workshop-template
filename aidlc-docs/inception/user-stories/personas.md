# User Personas - 테이블오더 서비스

---

## Persona 1: 고객 (Customer)

### 프로필
- **이름**: 김민수 (대표 페르소나)
- **역할**: 식당 이용 고객
- **연령대**: 20~50대
- **기술 수준**: 스마트폰/태블릿 기본 사용 가능

### 목표
- 대기 시간 없이 빠르게 주문하고 싶다
- 메뉴를 쉽게 탐색하고 선택하고 싶다
- 주문 상태를 실시간으로 확인하고 싶다

### 동기
- 직원 호출 없이 편하게 주문
- 메뉴 이미지와 설명을 보고 신중하게 선택
- 추가 주문을 간편하게 처리

### 페인포인트
- 직원을 기다리는 시간이 길다
- 메뉴판이 불명확하거나 가격 정보가 부족하다
- 주문이 제대로 들어갔는지 불안하다

### 사용 환경
- 태블릿 (매장 비치) 또는 QR 코드 스캔 후 모바일 웹
- 터치 기반 인터랙션
- 식사 중 간헐적 사용

---

## Persona 2: 매장 관리자 (Admin)

### 프로필
- **이름**: 박서연 (대표 페르소나)
- **역할**: 매장 운영자/사장
- **연령대**: 30~60대
- **기술 수준**: 기본적인 웹 서비스 사용 가능

### 목표
- 들어오는 주문을 실시간으로 파악하고 싶다
- 메뉴와 테이블을 효율적으로 관리하고 싶다
- 매장 운영 효율성을 높이고 싶다

### 동기
- 인건비 절감 (주문 접수 인력 감소)
- 주문 누락 방지
- 테이블 회전율 향상

### 페인포인트
- 바쁜 시간대에 주문을 놓치거나 잘못 전달한다
- 테이블별 주문 현황 파악이 어렵다
- 메뉴 변경 시 메뉴판 교체 비용과 시간이 든다

### 사용 환경
- 데스크톱 브라우저 또는 태블릿/모바일 (반응형)
- 매장 운영 중 지속적 모니터링
- 다중 매장 관리 가능
